# RHODIUM PUBLIC DISCLOSURE POLICY

ALLOW:
- public test inputs or public references
- explicitly reviewed public-safe verification code
- SHA-256 input/restore hashes
- scoped benchmark measurements
- PASS/FAIL evidence
- public run IDs / attestations

DENY:
- Rhodium core
- Matrix implementation
- reconstruction algorithms
- internal transformation rules
- private keys
- tokens
- passwords
- credentials
- internal filesystem paths
- Mama/Worker/Research control code
- private manifests
- unpublished customer data
- research runtime
- anything not explicitly allowlisted

DEFAULT POLICY: DENY
